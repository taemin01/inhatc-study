1. 공장은 주문을 받음(T404 기간까지 납품 주문)
2. 납품 가능 기간 맞추기(계획 및 예측 진행 시스템(APS)이 없으면 엑셀로 작성해서 일일이 진행해야함)
3. 시나리오 추출해서 양식에 맞게 수정해서 올려서 시나리오 진행해도 됨
4. 제공 된 데이터 기준정보 만들어서 업로드 해보는 것

- 프로젝트는 진행사항 발표(약식?으로)

#### 필독
- 주문 들어오면 생산 예측치를 드리는 프로세스(보고서는 이런식으로 작성하는 듯)
- 주문에 대한 시뮬레이션 진행하려면 데이터를 넣어야 함
- 프로세스 정형화 -> AI Agent 사용 가능
- 시나리오 복제해서 데이터 분석하고 돌려보기
- 주문 추가했을 때 어떤 예측치가 나오는지 진행해보기, 주문 정보를 추가해보는 걸 추천한다고 하심
- 프로젝트 (발표), 해당 과제는 모르겠음
- 실행 관리에서 내 시나리오 누르고 +버튼 누르면 start stop remove 버튼 활성화 됨
- 생산 계획 간트는 결과에 대한 간트 차트가 나옴(내 시나리오를 선택해야함)
- 시나리오 실행 해보고 예측치 보고 간트차트 본 후 보고서 작성하는 느낌의 과제인 듯
- 보고서에 주문 들어온 거 보고 데이터를 통해 시나리오를 시뮬레이션 하여 예측할 수 있다 라는 식의 작성

#### 과제 정리
- 생산 예측 계획 -> 프로세스
1. 주문 접수
2. 생산 예측 및 계획 수립 진행
3. 생산 기준정보 수집, 수집 정보 분석, 이후 예측 진행 하고 난 결과 도출, 
   이 과정이 기업에서 하는 프로세스이며, 결과를 고객사에 전달함

- 주문에 대한 예측행위를 고객사에게 보여주어 언제까지 줄 수 있는지 알려준다. 
  지금 실습하는 것이 이런 프로세스이다.
- 엑셀로 기준정보 받았으며 수집 진행
  분석을 현재 사용하는 툴을 사용해서 하는 것
  결과를 간트 차트로 보는 것
- 시나리오 만들어서 저 프로세스를 돌려보고 보고서 작성
  인사이트, 느낀 점, 생각 보고서에 정리
